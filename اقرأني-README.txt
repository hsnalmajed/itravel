===============================================
تحديثات موقع iTravel — جاهزة للرفع
===============================================

ليش هذا الملف؟
جلسة Claude عندها صلاحية "قراءة" فقط على مستودع itravel على GitHub،
وما عندها صلاحية "رفع/كتابة" — وهذا قيد أمني مفروض من النظام لا يمكن
تجاوزه من داخل الجلسة. فبدل ما ننتظر، هذي التعديلات جاهزة ترفعها أنت
بنفسك من جهازك، لأن جهازك عنده صلاحية كاملة على المستودع.


ماذا يوجد في هذي التعديلات؟
1) صفحة "المعالم السياحية" صار فيها شبكة صور لكل وجهة (مثل Viator)
   بدل القائمة النصية.
2) السعر صار رقم تقريبي فعلي (مثال: ~١٠٠–٣٠٠ ر.س / ~25–80$ للشخص)
   بدل كلمة "منخفض / متوسط / مرتفع".
3) زر "احجز الآن" يفتح صفحة الحجز في Viator مباشرة بدون وسيط.
4) خانات "طيران + فنادق / طيران فقط / فنادق فقط" ما عادت تظهر إلا
   بعد ما تختار "لدي وجهة محددة" أو "اقترح لي وجهة".

كل التعديلات تم فحصها: TypeScript و ESLint و البناء (build) كلها نظيفة.


===============================================
الطريقة (أ) — الأسهل، بدون أي برامج، من المتصفح
===============================================
مناسبة إذا ما عندك Git مثبت على الجهاز.

1. افتح: https://github.com/hsnalmajed/itravel
2. اضغط زر "Add file"  ثم  "Upload files"
3. افتح مجلد "updated-files" الموجود هنا، وأسحب مجلد "src" اللي
   بداخله وأفلته في صفحة GitHub.
   (مهم: اسحب مجلد src نفسه — GitHub بيحافظ على ترتيب المجلدات
    وبيستبدل الملفات القديمة تلقائياً)
4. تحت الصفحة اكتب أي وصف مثل: update attractions page
5. اضغط "Commit changes"

خلاص. بعدها Cloudflare بيعيد بناء الموقع تلقائياً خلال دقيقة-دقيقتين.


===============================================
الطريقة (ب) — إذا عندك Git على الجهاز
===============================================
افتح Command Prompt ونفّذ:

    cd %USERPROFILE%\Downloads
    git clone https://github.com/hsnalmajed/itravel
    cd itravel
    git pull "%USERPROFILE%\Downloads\itravel-update\itravel-updates.bundle" main
    git push origin main

هذي الطريقة أنظف لأنها تحافظ على الثلاث commits بأوصافها الأصلية.
